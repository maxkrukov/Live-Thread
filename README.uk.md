# Live Thread

![Python 3.10+](https://img.shields.io/badge/python-3.10%2B-blue)
![Platform Linux](https://img.shields.io/badge/platform-Linux%20(PipeWire%20%2F%20PulseAudio)-informational)
![License MIT](https://img.shields.io/badge/license-MIT-green)

**Живий тред тем і коротких нотаток для будь-якої розмови.** Live Thread слухає системний звук (і за бажанням мікрофон) під час відео, дзвінка, лекції, співбесіди чи подкасту, розпізнає мовлення, визначає *про що зараз ідеться* і веде поруч компактний тред нотаток: **уточнення · виправлення · підтвердження · доповнення · відповіді**. Коли розмова переходить до нової теми, застосунок створює картку теми з коротким оглядом ключових пунктів.

[English version](README.md) · [Changelog](CHANGELOG.md) · [Contributing](CONTRIBUTING.md)

## Можливості

- **Самоадаптація** — визначає тип контенту (технічна співбесіда, лекція, мітинг, подкаст, новини, фільм, чат…), витягує терміни й типові помилки розпізнавання та підставляє їх у Whisper і LLM.
- **Пресети режимів** — `auto`, `interview`, `lecture`, `meeting`, `media` адаптують фокус нотаток під контекст розмови.
- **Режим Q&A та рядок запитань** — автоматично ловить запитання в розмові й стрімить лаконічні відповіді у Markdown, а також дозволяє поставити власне запитання в будь-який момент (клавіша `/`).
- **Рядок «Зараз» і картки тем** — поточна суть розмови в ≤10 словах, картки тем з миттєвим оглядом, закріплення та приховування нотаток.
- **Перевірка фактів і фільтрація шуму** — дублікати, перекази, здогадки й коментарі про помилки розпізнавання відфільтровуються, а твердження перевіряються до показу.
- **Розділення мовців (діаризація)** — `S1`, `S2`, `S3`… за голосом через `sherpa-onnx` + TitaNet (опційно).
- **Гнучкий вибір джерел звуку** — системний вихід PipeWire/PulseAudio (`@DEFAULT_MONITOR@`), опційно мікрофон (`@DEFAULT_SOURCE@`) і вибір пристроїв у налаштуваннях.
- **Підсумки та історія сесій** — генерація саммарі на вимогу та перегляд/пошук/копіювання/завантаження/видалення збережених сесій у `~/.config/live-thread/sessions/*.md`.
- **Метрики** — затримки (`p50`/`p95`), нотаток/хв, відфільтровані нотатки, черга та помилки прямо в UI, у JSON (`/api/metrics`) та у форматі Prometheus (`/metrics`).
- **Багатомовний інтерфейс і мова нотаток** — UI українською, англійською, російською та польською; нотатки мовою розмови або вибраною фіксованою мовою.
- **Керування вікном (KDE Plasma)** — прозорість і режим «поверх інших вікон» через KWin scripting.
- **Приватність за замовчуванням** — сервер слухає лише `127.0.0.1:8765`, а звук і текст надсилаються тільки на сервери, які ви самі вказали.

> Використовуйте відповідально: у багатьох країнах необхідно попереджати співрозмовників про запис або транскрибацію розмови.

## Як це працює

```text
системний звук (+ мікрофон) ──► фрази (VAD) ──► розпізнавання ──► мовці (S1/S2) ──► двигун треду ──► веб-UI
   (PipeWire/PulseAudio)       0.5 с / 6 с      віддалений STT     TitaNet ONNX      будь-який       (SSE)
                                                або faster-whisper  (опційно)        OpenAI-LLM
```

## Вимоги

- Linux із PipeWire або PulseAudio (`parec`, `pactl`), Python 3.10+
- **OpenAI-сумісний** `/v1/chat/completions` ендпойнт (vLLM, sglang, llama.cpp server, Ollama, LM Studio, OpenAI, OpenRouter тощо). Найкраще працюють інструктивні моделі 20–30B+.
- Опційно: віддалений сервер Whisper STT для швидшого розпізнавання
- Опційно: KDE Plasma (`qdbus`) для прозорості й закріплення вікна

## Встановлення

```bash
git clone https://github.com/maxkrukov/Live-Thread.git live-thread && cd live-thread
./scripts/install.sh            # --no-diarization — без розділення мовців, --no-desktop — без ярлика в меню
live-thread                     # або запустіть «Live Thread» з меню застосунків
```

Відкрийте **Налаштування (⚙)** у веб-інтерфейсі (`http://127.0.0.1:8765/`) та вкажіть адресу LLM (`llm_url`) і назву моделі (`llm_model`). Налаштування зберігаються у `~/.config/live-thread/config.json` (права `600`). Приклад усіх параметрів див. у [`config.example.json`](config.example.json).

### Параметри CLI

```bash
live-thread [--port 8765] [--host 127.0.0.1] [--no-open] [--listen] [--debug] [--version]
```

## Гарячі клавіші

| Комбінація | Дія |
|---|---|
| `/` | Фокус на рядок запитань |
| `Esc` | Зняти фокус або закрити відкриту панель |
| `Alt + L` | Почати / зупинити прослуховування |
| `Alt + Q` | Увімкнути / вимкнути режим Q&A |
| `Alt + A` | Примусово відповісти на останні репліки |
| `Alt + S` | Згенерувати закріплений Markdown-підсумок сесії |
| `Alt + H` | Відкрити / закрити історію збережених сесій |

### Структура коду

- `live_thread/__main__.py` — точка входу CLI та запуск браузера
- `live_thread/audio.py` — захоплення аудіо через `parec` і нарізка фраз за енергією
- `live_thread/stt.py` — клієнт віддаленого STT + локальний `faster-whisper` і фільтрація галюцинацій
- `live_thread/diarize.py` — онлайн-діаризація мовців (`sherpa-onnx` TitaNet)
- `live_thread/engine.py` — двигун треду, профіль контенту, Q&A, фактчек, саммарі та експорт сесій
- `live_thread/llm.py` — OpenAI-сумісний потоковий клієнт LLM
- `live_thread/server.py` — HTTP-сервер, REST API, SSE і роздача веб-інтерфейсу
- `live_thread/events.py` — шина подій SSE
- `live_thread/metrics.py` — лічильники, квантилі затримок і експорт у Prometheus
- `live_thread/config.py` — завантаження/збереження конфігурації (`0600`) та валідація
- `live_thread/window.py` — керування вікном у KDE Plasma (KWin)
- `live_thread/web/` — фронтенд (`index.html`, `app.js`, `i18n.js`, `style.css`, `icon.svg`)
